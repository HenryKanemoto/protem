Acessibilidade

O Protem foi pensado para ser usado por qualquer pessoa da instituição. Usamos como referência as WCAG 2.1, nível AA, as diretrizes de acessibilidade para conteúdo web do W3C.

O que você pode ajustar

Em qualquer tela há o botão de acessibilidade (o boneco no topo). Suas escolhas valem na hora e ficam salvas neste navegador, para o seu usuário.

    @for (ajuste of ajustes; track ajuste.titulo) {

  • {{ ajuste.titulo }}

    {{ ajuste.texto }}

    • }

O que já vem pronto

    @for (texto of jaFazemos; track texto) {
  • {{ texto }}
    • }

Usando só o teclado

  • Tab e Shift + Tab andam entre botões, links e campos.
  • Enter ou Espaço ativam o item em foco.
  • Esc fecha diálogos e painéis, e o foco volta para onde estava.

O que ainda não temos

    @for (texto of aindaNao; track texto) {
  • {{ texto }}
    • }

Encontrou uma barreira?

Se algo no Protem dificultar o seu uso, avise o responsável pelo acervo da sua instituição. Cada relato ajuda a melhorar a plataforma.
